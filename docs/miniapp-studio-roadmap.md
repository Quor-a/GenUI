# GenUI 移动端技术架构总纲 & 小程序工作室路线图

> v0.28.6 基线。TA 定调的十大方向，逐项现状→方案→里程碑。

## 1. 移动端技术架构（总纲）
```
┌─ Studio 层（规划 v0.30）───────────────────────────┐
│ 小程序工作室：创建/编辑/排版/预览/发布/热更管理 + 后端 │
├─ 交付层 ─────────────────────────────────────────┤
│ 对话卡片 │ 画布内嵌 │ 全屏宿主 │ 网站版导出(独立HTML) │
├─ 双渲染引擎 ──────────────────────────────────────┤
│ WebView 通道(CSS全量) │ Skyline 自研引擎(Skia/GLES20) │
├─ 逻辑层 ─────────────────────────────────────────┤
│ 自研 C++ JS 引擎 + 60+ wx API + 权限门禁/域名白名单   │
├─ 资源层 ─────────────────────────────────────────┤
│ 包内二进制(图片/字体/媒体) + 网络加载 + LruCache      │
└──────────────────────────────────────────────────┘
```

## 2. 十大方向对照
| # | 方向 | 现状 | 里程碑 |
|---|---|---|---|
| 1 | 移动端技术架构 | 本文档 | 持续演进 |
| 2 | 更多开发语言 | 微信语法 ✓ + WebView 通道全语法 JS；**规划**：模板 template/include、WXS、React-like DSL | v0.29 DSL 评估 |
| 3 | 小程序工作室(后端) | ❌ | **v0.30 Studio**：工作台 UI（列表/新建/编辑器/实时预览）+ **Studio 后端**（genapi：包管理/版本/分发/统计，复用 genui-backend 框架） |
| 4 | 界面排版 | flex/absolute/渐变/阴影 ✓ | 排版增强：栅格/对齐辅助/边距系统 v0.29 |
| 5 | 组件 | 基础+形态组件 | **自定义组件 Component()+slot v0.29**；组件市场（工作室分发）v0.31 |
| 6 | UI | 无系统 UI 库 | **内置 UI 组件库**（AI 可引用的成套风格组件：卡片/导航/表单/图表模板）v0.29 |
| 7 | 自适应 | rpx+viewport ✓；**缺**：平板多列/横竖屏/分屏 | v0.29：断点系统（rpx 上限/媒体查询子集/adaptive 容器） |
| 8 | 字体引用 | 资源通道 ✓ | **v0.28.6 loadFontFace 实装**（网络/包内 ttf） |
| 9 | 网站版小程序 | WebView 通道本质即 Web 渲染 | **v0.28.6 export_miniapp_web 实装**（整包→独立 HTML 分发） |
| 10 | 热更新 | 重新生成即热更（GenUI 天然）；**缺**版本管理 | v0.30：包 version 戳+变更推送（工作室后端下发） |

## 3. 依赖关系
Studio(3) 依赖 组件库(5)+UI库(6)+排版(4) 成熟 → 组件库依赖 自定义组件(5) → 语言扩展(2) 服务于组件与 Studio 编辑器 → 自适应(7) 贯穿全部 UI 层 → 热更新(10) 依赖 Studio 后端(3)。
